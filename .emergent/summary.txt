**Key Technical Concepts**
-   **Database-Driven UI:** The calculator's entire structure (fields, formulas, etc.) is defined in the database via an admin panel, not in code.
-   **Dynamic Formula Evaluation:** The backend evaluates mathematical formulas stored as strings in the database to perform calculations.
-   **Material Families:** An abstraction () allows a single calculator template to work for a group of similar materials (e.g., a Steel calculator for all steel types).
-   **Component-Based Architecture:** The application is structured with reusable React components, with clear separation between display logic, data fetching, and state management.
